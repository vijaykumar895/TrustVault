# TrustVault – Secure Document Management System

## About the Project
TrustVault is a secure document management system developed using Python, Flask, and SQLite. It allows users to upload, download, search, manage, and share documents securely.

## Features
- User Registration and Login
- Admin, Owner, and Viewer Roles
- Document Upload and Download
- Search Documents
- Document Categories
- Share Documents with Other Users
- View and Edit Permissions
- Revoke Document Access
- User Profile Management
- Change Password
- Activity Logs
- Admin Dashboard and User Management

## Technologies Used
- **Backend:** Python, Flask
- **Database:** SQLite
- **Frontend:** HTML, CSS, JavaScript
- **Code Editor:** Visual Studio Code
- **Version Control:** Git and GitHub

## Installation and Setup

### Step 1: Clone the Repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open the Project Folder
```bash
cd TrustVault
```

### Step 3: Create a Virtual Environment
```bash
python -m venv .venv
```

### Step 4: Activate the Virtual Environment
For Windows:
```bash
.venv\Scripts\activate
```

### Step 5: Install Required Packages
```bash
pip install -r requirements.txt
```

### Step 6: Run the Application
```bash
python run.py
```

### Step 7: Open in Browser
```text
http://127.0.0.1:5000
```

## Project Objective
The objective of TrustVault is to provide a simple and user-friendly platform for secure document storage, sharing, and access management.
